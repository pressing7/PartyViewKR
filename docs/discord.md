# 개인 디스코드 봇으로 PVKR 조작하기 (0.3.37)

각 사용자가 **자신의 봇을 만들고 자신의 PC의 PVKR에 토큰을 등록**합니다. 게임 PC가 Discord Gateway에 직접 연결하므로 별도의 Cloudflare Worker, 공용 중계 서버, 포트 개방이 필요하지 않습니다. 게임과 PVKR은 켜져 있어야 합니다.

## 1. 개인 봇 만들기

1. [Discord Developer Portal](https://discord.com/developers/applications)에서 **New Application**을 누릅니다. 이름은 원하는 대로 정하고, 팀이 아닌 본인 계정 소유로 만듭니다.
2. **Installation**에서 **Guild Install**을 켭니다. **Install Link**는 **None**으로 두어도 됩니다. 초대 링크는 PVKR에서 제공합니다.
3. **Bot**에서 **Public Bot**을 끕니다. **Requires OAuth2 Code Grant**도 끈 상태로 둡니다. **Privileged Gateway Intents**는 모두 꺼도 됩니다.
4. **Bot → Token → Reset Token**으로 토큰을 발급하고 복사합니다. Application ID, Public Key, Client Secret과는 다른 값입니다. 토큰은 채팅·GitHub에 올리지 말고 PVKR 입력란에만 넣습니다.
5. **General Information → Interactions Endpoint URL**은 비워 둡니다. PVKR은 HTTP 수신 주소 대신 Gateway로 명령을 받습니다.

이미 다른 프로그램에서 쓰는 봇 대신 PVKR 전용 봇 하나를 만드세요. 같은 봇 토큰을 여러 게임 PC에 동시에 연결하지 않습니다.

## 2. 게임 PC 연결

1. 게임에서 `/pvkr`를 열고 **외부 접속 · 개인 디스코드 봇**을 펼칩니다.
2. **개인 봇 토큰**에 복사한 값을 붙여넣습니다.
3. 원하면 **토큰 저장 (이 Windows 계정에서 암호화)**을 체크합니다. 체크하지 않으면 다음 실행 때 다시 입력합니다. 저장해도 연결은 직접 켜야 합니다.
4. **디스코드 연결 켜기**를 누릅니다.
5. **내 봇 초대 링크 복사**로 링크를 열고, 본인이 관리하는 Discord 서버에 봇을 초대합니다. 관리자 권한이나 메시지 내용 읽기 권한을 부여할 필요가 없습니다.
6. 연결 상태가 **연결됨**인지 확인합니다.

다른 Windows 계정이나 PC에서는 저장한 토큰을 복호화할 수 없으므로 다시 입력합니다. **저장한 봇 토큰 삭제**는 저장본을 지우며, 현재 접속도 끊으려면 **디스코드 연결 끄기**를 누릅니다.

## 3. 휴대폰에서 사용

서버의 봇 프로필에서 DM을 열고 **`/pvkr`**를 입력합니다. 처음 명령이 목록에 나타날 때까지 잠시 걸릴 수 있습니다. 서버 채널에서 실행해도 응답은 본인에게만 표시됩니다. 실제 조작 권한은 봇 애플리케이션 소유자의 Discord 계정으로 제한합니다.

| 조작 | 동작 |
| --- | --- |
| `/pvkr`, 다시 조회 | 게임에서 내 모집글을 새로 조회. 유효한 편집 내용이 있으면 `/pvkr`는 편집 카드 복원 |
| 갱신 | 현재 조건을 유지하고 갱신 |
| 수정 | **새 편집 카드**를 보내 소개말·모집 조건·참가 규칙·비공개·자리/직업 구역 표시 |
| 함께 수정 | 해당 구역의 여러 설정을 하나의 입력창에서 수정 |
| 켜기 / 끄기 | 초행 환영·잡 중복·참가 규칙을 대기 목록에 바로 반영 |
| 자리·직업 수정 | 새 편집 카드에서 파티와 빈자리를 고른 뒤 허용 직업 선택 |
| 적용 및 갱신 | 모아 둔 변경을 한 번에 처리하고 갱신 |
| 상태 확인 | 게임에 새 조회를 보내지 않고 PVKR의 최근 상태 표시 |

조회 카드에는 콘텐츠, 인원, 남은 시간, 소개말과 파티별 자리 목록을 표시합니다. 편집 카드는 별도 메시지이며 항목별 변경 전·후 값과 대기 개수를 보여줍니다. 이동해도 변경사항은 유지합니다. **적용 및 갱신** 후에는 그 카드가 결과와 최신 모집 정보를 보여주는 조회 카드로 바뀝니다. 편집 내용이 남아 있을 때 이전 조회 카드에서 조회·갱신·상태 확인을 누르면 편집 카드에서 먼저 적용하도록 안내합니다.

24·48인 모집은 A~F 파티, 친선경기는 별빛팀·그림자팀·관전으로 나눕니다. 미등록 칸을 제외한 실제 자리 번호를 유지하며 참가자가 있는 자리는 편집할 수 없습니다. 직업 선택 메뉴는 기존 PVKR의 순서대로 두 묶음으로 나눕니다. 한 묶음의 선택을 바꿔도 다른 묶음의 선택은 유지합니다. **전체 선택·선택 비우기·탱커·힐러·딜러**로 빠르게 선택할 수 있습니다. 역할 버튼은 해당 잡만 선택하며 클래스는 메뉴에서 추가합니다. 허용 직업이 하나도 없는 변경은 적용할 수 없습니다.

소개말은 UTF-8 192바이트까지, 평균 아이템 레벨은 1~999입니다. 평균 아이템 레벨 입력에 **0**을 넣으면 제한을 끕니다. 비공개를 새로 켤 때는 **0000~9999의 숫자 네 자리**를 입력합니다. 이미 비공개이거나 이번 편집에서 비밀번호를 입력했다면, 입력창을 다시 열어 비밀번호를 비워 두어도 해당 값을 유지합니다. 다른 항목만 수정해도 기존 비밀번호는 유지합니다. 입력한 비밀번호를 카드·입력창에 다시 표시하거나 진단 로그에 남기지 않습니다.

콘텐츠에서 사용할 수 없는 조건은 기존 일괄 수정 동작대로 건너뛰고, 갱신 후 적용·미적용·확인 필요 개수와 사유를 안내합니다. 참가자나 모집 조건이 바뀌어 편집 기준이 달라지면 `/pvkr`로 다시 조회합니다. 편집 카드를 다시 열면 이전 편집 카드의 버튼은 만료됩니다. 조회 카드는 별도로 유지되며, 적용을 마친 뒤에는 최신 결과 카드에서 조작합니다. 조작하지 않은 카드는 15분 후 만료됩니다.

## 연결이 안 될 때

- **0.3.35에서 첫 화면만 열리고 버튼은 응답 시간 초과**: 버튼 입력 처리 오류가 있으므로 0.3.36 이상으로 업데이트합니다. 다시 연결한 뒤 `/pvkr`로 새 화면을 엽니다. 기존 봇과 토큰을 그대로 사용합니다.
- **0.3.34 사용 중**: 명령어 등록 순서 오류가 있으므로 버튼 오류 수정도 포함된 0.3.36 이상으로 업데이트합니다. 기존 봇과 토큰을 그대로 사용할 수 있습니다.
- **연결 시작 실패**: PVKR에 표시된 `단계`와 오류 번호를 확인합니다. 봇 정보 확인과 명령어 등록 실패를 구분할 수 있으며, 문제를 제보할 때는 이 상태 문구만 보내고 토큰은 보내지 않습니다.
- **토큰 오류**: Developer Portal의 **Bot** 토큰인지 확인하고 다시 입력합니다. Reset Token을 다시 눌렀다면 이전 토큰은 사용할 수 없습니다.
- **팀 소유 앱 안내**: 본인 계정 소유의 별도 애플리케이션을 만듭니다.
- **봇은 연결됐지만 명령이 안 옴**: 봇을 서버에 초대했는지, `applications.commands` 권한이 포함됐는지, Interactions Endpoint URL이 비어 있는지 확인합니다. 명령 목록 반영 후 다시 입력합니다.
- **화면 만료 / 모집 정보 변경**: `/pvkr`로 다시 엽니다. 현재 기준이 유효하면 작성 중인 변경 목록을 유지합니다.
- **게임에서 처리 중**: 앞선 요청이 끝난 뒤 확인합니다. 연결 오류가 나도 이미 시작한 갱신을 자동으로 재실행하지 않습니다.
- **게임 수정창 / PVKR 편집 중**: 해당 작업을 먼저 끝낸 뒤 디스코드에서 다시 조회합니다.

같은 PC 브라우저, Cloudflare 외부 브라우저, Discord 연결은 한 번에 하나를 사용합니다. 기존 웹 기능은 유지합니다. 이번 버전은 요청에 대한 조회·수정·갱신 화면을 제공하며, 파티원 입장 등 자동 알림은 포함하지 않습니다.

## 개발 검증

관리 코드 331개 테스트와 로컬 Release 빌드를 통과했습니다. 소유자·앱 ID 확인, 중복 요청, 응답 접수 실패 시 실행 차단, 오래된 모집 정보, 친선경기·48인 자리, 두 직업 메뉴의 선택 보존, 비밀번호 0000, 일부 항목 실패 후 갱신을 검사합니다. 실제 Discord.Net 라이브러리에 모의 REST/Gateway 응답을 주어 연결 초기화, 새 편집 메시지 생성, Components V2 응답과 제한, 버튼·선택 메뉴·라디오·체크박스·소개말·비밀번호 입력 및 일괄 갱신을 확인합니다. 실제 개인 봇 연결, Android Discord 화면, Windows 토큰 암호화 및 인게임 반영은 사용자의 환경에서 확인해야 합니다. Actions 빌드와 배포는 사용자가 실행합니다.

구현은 [Discord Gateway](https://docs.discord.com/developers/events/gateway), [Interactions](https://docs.discord.com/developers/interactions/receiving-and-responding), [Components](https://docs.discord.com/developers/components/reference), [Discord.Net](https://docs.discordnet.dev/) API를 사용합니다. 봇 만들기 기본 절차는 [Discord 공식 시작 안내](https://docs.discord.com/developers/quick-start/getting-started)를 참고할 수 있습니다.
